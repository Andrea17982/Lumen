# Lumen 0.12.5 — A new desktop app

Release 0.12.5, 24 November 2026. The desktop interface is rewritten from scratch. The service underneath is the same one 0.12.2 shipped, with a few fixes; your accounts, projects and conversations carry over.

## What it looks like now

- **One window, two looks.** Ink (warm paper, an ember accent) is the default; Satin (cool, indigo) is the alternative in Settings. Both follow the system's light or dark mode and use system fonts.
- **Projects and conversations.** One project open at a time, its conversations grouped by day, with search, pin, drag to reorder, move and delete. A side panel shows the project's `LUMEN.md`, what the conversation has settled, its recurring tasks, the project's checks and the log of what agents did.
- **The conversation.** Replies stream as Markdown; tool calls, commands and file changes fold into one line you can open. Stop is always there. Long conversations (tested at 5,000 messages) keep native search, selection and screen reader access.
- **When Lumen needs you.** Approvals, questions (secret answers stay out of the transcript), resume when a quota resets, rewind with a preview of what it undoes, and "continue in a new conversation".
- **Accounts.** Sign in through each agent's own CLI, see the quota each one reports (or that it reported nothing), and add API keys that go to the system keychain and never come back to the screen.
- **Orchestra and Code Mode are switches.** Each has one line saying what it does. Orchestra's plan, questions and live lanes appear on the message that runs it, with resume after a crash.
- **Extensions.** Plugins show what they ask for and what they add before you install them; their panels run sandboxed. MCP servers, skills and the integrations your agents already have are in the same place.
- **Task branches.** A large task runs on its own branch; a bar above the conversation offers Publish, Apply and Discard.
- **Desktop.** Notification area icon, notifications when a reply is ready or Lumen needs you (only when the window is not in front), a screenshot button in the message box, `/every` for recurring tasks, Italian and English.

## Fixes in the service

- Adding a project canonicalizes the folder, so conversations started from a short Windows path still belong to it.
- Plugin panels can no longer fetch IP addresses or `localhost` names, even if declared.

## Checks

- Automated: 341 Rust tests (17 opt-in ignored), 104 client unit tests, 63 browser tests against the real service with offline fixtures (accessibility checks included), and a real-app WebDriver test of the shell (service start, crash recovery, plugin panel cannot reach the shell).
- Built and smoke-tested here on Windows x64. This release ships the Windows installer only; macOS and Linux build from source.

## Upgrading

Close active work, then run the new setup. Settings removed from the interface keep their saved values and defaults; the global capture shortcut is gone, use the screenshot button instead.
