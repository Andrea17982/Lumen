# Lumen 0.17.0

- **Apply on task branches** preserves file bytes, including legacy encodings. When the service stops during Apply, Lumen checks the recorded changes before retrying. If it cannot confirm the project state, it keeps the task folder for review.
- **Discard** returns the conversation to your project and shows where the task files will stay. Files created after Publish stay there too. After a pull request merges, the conversation returns to the project and Lumen keeps the task folder for recovery.
- **Claude and Codex sub-agents** cannot approve requests or finish the parent turn through Lumen. Claude delegation is available in Autopilot. Lumen disables delegation in permission profiles that restrict operations.
- **Publish PR and Undo changes** are available from Settings › General. Publish targets the project's GitHub `origin` in one click. Undo returns the conversation to your project and keeps the isolated task files for recovery.
- **Ctrl+Enter** queues messages while a turn runs. Lumen sends them in order after successful turns and keeps them available to recover after Stop or an interruption.
- **Model selection** follows the current catalog and reserves frontier models in Auto for the hardest tasks. When connecting Claude Code, choose whether the plan includes Fable and Mythos in **Settings › Accounts**. A Claude spending-limit response temporarily removes the affected model and its aliases without cooling down the whole account.
- **Conversation layout** has a shorter header, a stable sidebar toggle, consistent motion and corner radii, and project details focused on shared notes and checks.
