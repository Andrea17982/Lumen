# Lumen 0.16.0

Guided first launch. A new installation opens a short setup for language, style, agents and the first project, followed by an optional tour. Codex tasks no longer stop when the agent starts sub-agents.

## Guided setup

- **Five short steps.**
  - Welcome.
  - Appearance: language, Ink or Satin, and light, dark or system theme, with a live preview.
  - Agents.
  - First project.
  - A summary of what is ready.
- **Agents.** Lumen finds the CLIs installed on your computer and shows each one as installed (with its version) or missing, and each account as ready or not connected. You can sign in from the same screen. Claude Code and Codex use the sign-in without a terminal from 0.15. An agent counts as ready only when its CLI confirms the sign-in.
- **Summary.** It says what is ready and what is still missing. Auto stays the default.
- **Skipping.** Every step can be skipped. Lumen remembers whether you finished or skipped the setup, so it does not open again on the next launch.
- **Updating from 0.15.** You keep your projects and see a small invitation to the setup, which you can open or dismiss.

## Quick tour

- After the setup, a tour points out the composer, the agent and access menus, Auto, Stop, the task bar, Orchestra and Maintenance. It highlights each control where it is.
- **Settings › General** opens the setup or the tour again.
- The setup and the tour work with the keyboard and screen readers. When the system asks for reduced motion, they do not animate.

## Reliability

- **Codex sub-agents no longer stop the task.** When Codex started sub-agents, their activity reached Lumen's approval checks as if it belonged to another task. Lumen then stopped the whole turn with "Approval belongs to another Codex thread or turn". Lumen now leaves sub-agent activity to Codex and shows it through the main agent. A request from a sub-agent is declined: nothing a sub-agent asks for is ever approved, not even in Autopilot.

## Compatibility

- The setup state is stored in a new table in the service database. If you go back to 0.15 with **Go back to**, 0.15 opens the database and ignores that table.
