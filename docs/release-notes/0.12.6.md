# Lumen 0.12.6

Release 0.12.6 improves Codex Autopilot and file attachments.

- Fixed a bug that could prevent Codex from editing files in Autopilot. Codex now uses its native approval flow in Autopilot.
- Codex Autopilot checks whether requested work is complete and can continue unfinished work in the same session.
- Attach files with the paperclip or drag them into the message box. Codex receives supported image attachments as native image input.
- The attachment button returns focus to the message field when the file picker opens.
- Use the Lumen logo to show or hide the sidebar. Default conversation titles follow the interface language.

Windows x64 builds require WebView2. Close active work before upgrading.
