# Lumen 0.5.0

## Highlights

- Removed the unreadable Project context panel. The composer paperclip opens the system picker for multiple files of any type, and Ctrl+V attaches clipboard images.
- Removed unsolicited screen capture. Claude Ask-first can call the session-scoped `list_screens` and `capture_screen` MCP tools when visual inspection is needed. Captures are saved in `.lumen/screenshots/` and returned to Claude as image content. Visual review remains user initiated. Other provider paths do not receive this MCP capability yet.
- Simplified Settings: Simple mode contains only the Orchestra switch; every other setting is in Advanced. General → Restore defaults resets Lumen preferences while preserving accounts, conversations and workspace selection.
- Added project-scoped Godot diagnostics, a repository symbol map with relevant references in prompts, `res://` integrity checks, layered change review and screenshot comparison.
- Added app-server based Codex approvals and improved multi-task Orchestra routing.
- Coordinated writes across conversations targeting the same project folder. Writes serialize, and Rewind/worktree integration guard against concurrent changes.
- Added the context meter, compact context action, file-at-line links, and screenshot/file attachment previews.

## Build and validation

Windows x64 portable and NSIS setup artifacts are built locally; the portable matches the compiled executable by SHA-256. `docs/validation.md` records the checks run here. Automated unit, browser and complete Rust test suites run in GitHub Actions before the workflow attaches Windows and macOS release artifacts.

## Known limits

- The model-requested screenshot MCP tools are currently available in Claude Ask-first sessions. They are not yet integrated into Codex, other providers, or non-Ask Claude sessions.
- Native UI verification and macOS/Linux behavior remain dependent on their respective environments.
