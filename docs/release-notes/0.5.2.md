# Lumen 0.5.2 — Lighter, faster, tidier settings

> Historical release notes. For the current product, read [Features](../features.md), [Validation](../validation.md) and the [latest changelog](0.7.0.md).

A smaller, quicker Lumen that spends fewer tokens on attachments, with a cleaner settings panel.

## Faster and lighter

- **Smaller app.** Release builds are now size-optimized: the Windows executable drops from 23.7 MB to 14.5 MB.
- **Cheaper attachments.** Text files up to 16 KB (48 KB in total) are still sent in full. Larger ones are passed by path with a short preview, and Claude and Codex read only the parts they need. A large file used to cost up to ~100k tokens per message; now it costs a few hundred.
- **Less background work.** Usage, provider status, Gatekeeper and Orchestra timers pause while Lumen is minimized or in the notification area, and refresh as soon as you return.
- **Quicker start.** Settings, Orchestra cards and the Gatekeeper panel load the first time you open them.

## Conversations

- **Pick the folder from the top bar.** In a new conversation, click the folder name next to the title to choose where it runs.

## Settings

- Scrolling stops at the end of the panel instead of dragging the whole window.
- General: "Appearance" is now **Interface**; the per-conversation folder moved to the top bar.
- Teamwork is grouped into **Orchestra**, **Reliability** and **Context**, and Simple mode explains what Orchestra does.
- Auto: "Balance usage" is a switch with an explanation, like the other options.
- Consistent separators: lines divide rows, never a title from its first row.
- About has a title, and the remaining English-only texts (Orchestra limits, hidden advanced options) are translated into Italian.

## Removed

- **Local API.** The OpenAI-compatible endpoint for other apps on this PC is gone, along with its settings and dependencies.

## Notes

- Unsigned alpha builds: Windows may show a publisher warning; on macOS right-click → Open the first time.
