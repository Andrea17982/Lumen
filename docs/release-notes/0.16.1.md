# Lumen 0.16.1

One Lumen at a time. Opening Lumen again now shows the window that is already open, so updates and **Go back** no longer stop halfway.

## Fixes

- **A second launch shows the open window.** When the window was in the tray, opening Lumen from the Start menu started a second copy. Both copies kept the service running. When one stopped the service to install an update or go back, the other restarted it, and Lumen stopped with "Another program answers on Lumen's service address". Now a second launch brings the open window to the front and exits.
- **The update banner** keeps **Later** and **Update** together on the right, with Update last. Update used to sit in the middle of the bar.

## From 0.16.0

- **Guided first launch.** Language, Ink or Satin with light, dark or system theme, the agents installed on your computer with their sign-in, the first project, and a summary of what is ready. An optional tour follows. Settings › General opens both again.
- **Codex sub-agents no longer stop the task.** Their activity used to end the turn with "Approval belongs to another Codex thread or turn". A request from a sub-agent is declined, never approved.
