# Lumen 0.4.0 — Orchestra

> Historical release notes. For the current product, read [Features](../features.md), [Validation](../validation.md) and the [latest changelog](0.7.0.md).

## New

- **Orchestra** (Settings → Teamwork, works with Auto). For complex tasks one orchestrator model asks clarifying questions with recommended answers, shows a plan with the agent assigned to each subtask (reassign or remove, then Approve), runs the subtasks in parallel git worktrees across every connected provider and integrates the result. The orchestrator follows the Auto preference; with Cross-audit on, the other provider validates the integration (Budget) or the plan and the integration (Default/Quality). Failed subtasks are retried once on another provider. A small **Orchestra** badge next to Auto shows when it is on.
- **Ollama** in Connected accounts, through the official `ollama` CLI. It is the last emergency fallback and takes trivial text-only Orchestra subtasks; it never edits files. Lumen uses the largest installed model, or the one you pin in Advanced mode.
- **Settings in sections** (General · Accounts · Auto · Teamwork · Tools · About) with a **Simple / Advanced** switch that hides expert options. Simple mode tells you when hidden options are on.
- **Notification area and login**: keep Lumen running when the window is closed (tray menu Open/Quit) and open it at login, starting hidden when the tray option is on.

## Important fixes

- **Codex can edit files on Windows again.** Lumen's isolated Codex accounts had no Windows sandbox setting, so in File edits Codex blocked every write. Lumen now runs Codex with the unelevated Windows sandbox, which needs no administrator prompt.
- **Antigravity works.** It never received the prompt (it ignores stdin in plain print mode) and its model list and output were not read. Lumen now sends the prompt as stream-json, reads its streamed answer and lists its models. In File edits Antigravity may run any command, because its command line cannot allow read-only commands alone; Lumen tells you once when you choose File edits with Antigravity connected.
- Git worktrees (Both and Orchestra) are checked out byte for byte, so their changes apply cleanly when `core.autocrlf` is on.
- Catalog aliases such as Claude's "Default (recommended)" no longer win over named models, so activity shows the model that actually runs.
- Popovers open next to what you clicked (Usage, Rename), the backdrop no longer lights up on hover, and controls no longer draw a focus ring.

## Notes

- Orchestra needs a git repository; in other folders the request runs normally and offers **Initialize git**. In Ask (read-only) mode the agents only analyze.
- An Orchestra run interrupted by closing Lumen is marked Interrupted at the next start, and its temporary worktrees are removed. Rewind on "Approved the plan." restores the files and reopens the plan.
- Unsigned alpha builds: Windows may show a publisher warning; on macOS right-click → Open the first time.
