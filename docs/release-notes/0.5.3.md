# Lumen 0.5.3 — Smoother streaming, quieter background

> Historical release notes. For the current product, read [Features](../features.md), [Validation](../validation.md) and the [latest changelog](0.7.0.md).

Long replies stream more smoothly, Lumen stops opening the Antigravity sign-in on its own, and the code underneath is reorganized.

## Faster

- **Smoother streaming.** Replies are drawn once per frame instead of on every chunk, and the view follows them without animating the scroll.
- **Long conversations stay light.** Earlier messages are rendered only when they scroll into view.

## Fixes

- **No more surprise Antigravity sign-in.** Usage was checked every 30 seconds, and on boot or wake that could open Chrome on the Antigravity login. Lumen now checks at most every 15 minutes, stops after a failure, and never asks the CLI to open a browser.
- **No console windows.** Every background process (git, shell commands, Godot, provider CLIs, process checks) now starts with its console hidden.
- **Resuming Orchestra.** After stopping a leftover CLI, Lumen waits for it to exit before reporting it, instead of sometimes warning that it was still running.
- Error messages no longer start with "Error:".

## Settings

- **Auto:** the manual quota snapshot editor ("Auto usage balancing") is gone. The tab keeps the preference (quality, balanced, savings) and the Balance usage switch.

## Under the hood

- The main window is split into reusable components: message view, sidebar lists, composer toolbar, error banner, attachment list and command palette entries.
- Shared helpers for saving settings, error text and data URLs replace several copies of the same code.
- New unit tests for the message helpers.

## Notes

- Unsigned alpha builds: Windows may show a publisher warning; on macOS right-click → Open the first time.
