# Example plugins

Install one from **Settings → Plugins** by choosing its folder. See [the plugin guide](../../docs/plugins.md).

| Folder | Shows | Permissions |
| --- | --- | --- |
| [dusk-theme](dusk-theme) | A theme made only of CSS tokens | none |
| [review-commands](review-commands) | Slash commands, a shared skill and a sandboxed panel | none |
| [word-count](word-count) | A small MCP tool server (needs Node.js) | none |
